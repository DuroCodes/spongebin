# spongebin (VS Code extension)

Create spongebin pastes from VS Code.

## Commands

- `spongebin: Create Paste from Selection`
- `spongebin: Create Paste from Input`

## Settings

- `spongebin.baseUrl` (default: `http://localhost:3000`)
- `spongebin.defaultLanguage` (default: `text`)
- `spongebin.theme` (default: `catppuccin-mocha`)

## Develop

```bash
cd vscode-extension
bun install
bun run compile
```

Then run the extension via VS Code: **Run and Debug** → **Run Extension**.
